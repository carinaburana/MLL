# Predicting Mental Health from Social Media User Data — Machine Learning 

A university course project exploring the relationship between social media usage and mental health through different machine learning.

The project compares three classification models: **Logistic Regression, Random Forest, and XGBoost**.

### Project Highlights
- Applied machine learning to a social media and mental health dataset.
- In-depth comparision of different modeling approaches and their predictive performance.
- Comprehensive data analysis and visualisation of meaningful results
- Explored **feature importance and tree visualizations** to better understand model behavior
- 

**Technologies:** Python, Jupyter Notebook, SciKit Learn, Pandas
